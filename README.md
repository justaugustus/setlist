# setlist

Talks and demos by Stephen Augustus, published at <https://justaugustus.github.io/setlist/>.

Each deck is Markdown under `decks/<name>/slides.md`, built with [Marp](https://marp.app/).

```sh
npm ci
npm run serve   # live preview at http://localhost:8080
npm run build   # static site in _site/
```

Pushes to `main` deploy to GitHub Pages.
